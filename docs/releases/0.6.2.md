# Omarchy YubiKey 0.6.2

Fix primary buttons becoming unreadable when hovered, pressed or focused.
The control center uses inverse text on a solid accent background, while the
Omarchy base button replaces its background with translucent state fills.
That left dark text against a nearly transparent dark surface during hover.

Primary buttons now keep their opaque accent surface in all interaction states.
The host's border, press animation, keyboard activation, disabled appearance and
click handling remain in place. Switching to a secondary button restores the
host's original color binding, including its normal hover/focus styling.

The native UI fixture now sends actual mouse and keyboard events and checks
rendered pixels and text contrast in dark and light palettes. It covers idle,
hover, press, focus, disabled clicks and switching the primary property at
runtime. Restoring the old button makes the dark-hover regression fail; the
corrected button passes. The fixture pauses its repeating timer during tests
so event/animation waits cannot trigger nested test runs.

Eight native UI runs cover English, German, Brazilian Portuguese and Arabic at
1280 and 640 px, including all existing navigation, confirmation and action
checks. CI checks the Python, JavaScript and Rust suites, catalogs, publication
content, build-output regression and source/history secret scans.

Suite/setup is **0.6.2**. Lock/Polkit remain **0.3.1** and the helper remains
**0.2.1**. This patch changes control-center visuals and its test fixture.

```sh
omarchy plugin update yubikey.setup
```

Downloads contain exact tagged source and SHA256SUMS. Existing
[0.6.0 qualification limits](0.6.0.md) and the
[0.6.1 deletion safeguard](0.6.1.md) continue to apply.
